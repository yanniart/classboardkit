## 문제와 해결
- E2E 기준선을 돌리는 도중 `canvas.js`·`clock`·`registry.js`를 sw-stamp 없이 고쳐 m3·m6이 앱 부팅 단계에서 실패 (`dock__item` 없음). 실행 중에는 앱 파일을 건드리지 말 것 — 최종 회귀로 확인
- 생성기 첫 구현이 표식 주석 **줄 중간**에 코드를 끼워 넣어 문법 오류 → 표식 줄 **위**에 넣도록 (여러 위젯을 만들어도 만든 순서대로 쌓이고 표식은 끝에 남음)
- 가이드에 "명단은 `items` 필드면 공유 링크가 자동으로 뺀다"고 썼다가 코드 확인 — 실제로는 `core/share.js`의 `NAME_FIELDS`에 등록된 타입만 → 가이드를 "NAME_FIELDS에 추가(PR에 명시)"로 수정
- JSDoc 타입 참조 `import('../../core/registry.js')`가 import 검사에 잡힘 → `core/registry.js`를 "타입 전용 공개 모듈"로
