# ADR-0004: 위젯 좌표를 캔버스 대비 비율로 저장

- 상태: **Accepted**
- 날짜: 2026-11-04

## 배경
주 사용 기기가 노트북(16:9, 16:10)과 태블릿(4:3 등, 가로/세로 회전)으로 화면 비율과 해상도가 다양하다. 내보낸 보드를 다른 기기에서 가져와도 배치가 유지되어야 한다.

## 선택지
1. 픽셀 절대 좌표
2. 캔버스 대비 비율(0~1)
3. 그리드 셀 단위 (예: 12×8)

## 결정
2번. `x, y, w, h`를 0~1 비율로 저장하고 렌더 시 캔버스 크기를 곱한다. 위젯 내부 콘텐츠는 Container Queries로 크기에 비례해 조정한다.

## 결과
- 장점: 기기·회전·창 크기 변화에 자연스럽게 대응
- 단점: 극단적 비율 차이(가로↔세로)에서 위젯이 납작해질 수 있음
- 보완: 위젯별 `minSize` 보장, 화면 비율이 크게 다를 때 "레이아웃 정리" 기능을 Phase 2에서 검토
