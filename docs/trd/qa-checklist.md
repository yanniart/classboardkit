## 2. 공통 (M0~)

- [ ] 첫 방문 시 브라우저 언어로 표시 (ko/en), 그 외 언어는 영어
- [ ] 설정 → 언어 전환 즉시 전체 문구(위젯 포함) 변경, 새로고침 후 유지
- [ ] 설정 → 테마 4종(시스템/라이트/다크/고대비) 전환 및 유지
- [ ] 시크릿 모드에서 "저장이 꺼져 있어요" 알림 표시, 앱은 정상 동작
- [ ] 콘솔 오류 없음

## 3. 캔버스·위젯 (M1)

- [ ] 독에서 위젯 추가 → 계단식 위치, 추가된 위젯에 포커스
- [ ] 제목 막대 드래그로 이동, 캔버스 밖으로 나가지 않음
- [ ] 오른쪽 아래 모서리로 크기 조절, 최소 크기 이하로 줄지 않음
- [ ] 위젯을 누르면 맨 앞으로
- [ ] 위젯 내부 버튼·입력 조작 시 드래그가 시작되지 않음 (터치 포함)
- [ ] 키보드: Tab으로 위젯 포커스 → 화살표 이동, Shift+화살표 큰 이동, Alt+화살표 크기, Delete 삭제
- [ ] × 버튼으로 삭제
- [ ] 창 크기 변경·태블릿 회전 시 배치 비율 유지
- [ ] 위젯 20개 상태에서 드래그가 끊기지 않음 (NFR-004)
- [ ] 툴바·독이 위젯에 가려지지 않음

## 4. 보드 (M1)

- [ ] 새 보드: "보드 n" 이름으로 생성·활성화, 빈 상태 문구 표시
- [ ] 이름 변경: 대화상자, Enter로 저장, 빈 이름은 저장 안 됨, 한글 IME 입력 중 Enter로 오작동 없음
- [ ] 복제: 원본 바로 뒤 "(사본)"으로 생성, 위젯 포함
- [ ] 삭제: 확인 대화상자(취소 시 유지), 마지막 보드 삭제 시 새 빈 보드 생성
- [ ] 보드 목록에서 전환, 현재 보드 표시
- [ ] 배경 12종 적용·유지, 어두운 배경에서 빈 상태 문구가 흰색
- [ ] 고대비 테마에서는 배경이 검정으로 고정
- [ ] 팝오버: 바깥 클릭·Esc로 닫힘

## 5. 위젯별 (M1 기본형)

### 타이머
- [ ] ±1분, ±10초 조정 (0:00 ~ 99:59)
- [ ] 시작 → 1초 단위 감소, 일시정지 → 계속, 초기화
- [ ] 0:00 도달 시 종료음(첫 상호작용 이후) + 깜빡임 + "시간 종료!"
- [ ] 진행 중 새로고침·탭 전환 후에도 남은 시간 정확
- [ ] 위젯을 낮게 줄이면 조정 버튼 숨김

### 텍스트
- [ ] 입력 내용 자동 저장·복원
- [ ] 글자 크게/작게(4단계), 정렬 순환
- [ ] 위젯 크기에 비례해 글자 크기 변화, 교실 뒤편에서 읽힘 (NFR-006)

## 6. 저장 (M0~)

- [ ] 조작 후 1초 이내 저장 (DevTools → Application → Local Storage `classboardkit:*`)
- [ ] 저장 데이터를 손상시키고 새로고침 → 알림 + `classboardkit:corrupt:*` 백업 생성 + 새 보드

## 7. 위젯별 (M2)

### 공통
- [ ] ⚙ 버튼은 설정이 있는 위젯에만 표시(스톱워치 제외), 완료·Esc로 닫힘
- [ ] 설정 패널이 위젯보다 길면 패널 안에서 스크롤

### 타이머
- [ ] 빠른 설정(1~30분) 선택 시 패널 닫힘·대기 상태
- [ ] 분·초 직접 입력 반영, 원형 모드에서 원이 줄어듦, 마지막 10초 빨간색
- [ ] 종료음 끄기 동작

### 스톱워치
- [ ] 1/100초 진행, 랩 기록(최신순), 정지 후 계속, 초기화

### 시계
- [ ] 디지털/아날로그, 12/24시간(오전·오후), 초·날짜 표시 토글, 언어별 날짜 형식

### 랜덤 뽑기
- [ ] 명단 붙여넣기(줄·쉼표), 중복 이름 제거
- [ ] 중복 제외 ON: 모두 뽑으면 버튼 비활성 + "모두 뽑았어요", 처음부터
- [ ] 연출 후 결과 표시, 움직임 줄이기 설정 시 즉시 표시

### 모둠 편성
- [ ] 모둠 수 / 모둠당 인원 전환, 모둠 크기 차 최대 1명, 다시 섞기
- [ ] 명단·규칙 변경 시 이전 결과 초기화

### 점수판
- [ ] ±1, 선두 팀 강조, 팀 2~8개, 이름·색 변경, 전체 초기화
- [ ] 이름 비우면 "n팀"(언어 전환 시 "Team n")

### 신호등
- [ ] 등 누르면 전환, 문구 편집, 빈 문구는 언어별 기본값
- [ ] 위젯을 가로로 넓히면 가로 배치

## 8. 안정화·출시 (M3)

### 내보내기/가져오기
- [ ] 보드 내보내기 → `classboardkit-<이름>-YYYYMMDD.classboardkit.json` 다운로드, 한글 이름 유지 (iPad: "파일"에 저장)
- [ ] 전체 내보내기 → 모든 보드 + 설정 포함
- [ ] 가져오기 → 보드가 뒤에 추가되고 활성화, "보드 n개를 가져왔어요"
- [ ] 같은 파일을 두 번 가져와도 충돌 없음 (별도 보드 2개)
- [ ] JSON 아닌 파일·다른 앱 파일·손상 파일 → 이유별 오류 알림, 보드 변화 없음
- [ ] 마지막 백업 표시: 없음(빨간색) → 오늘 → n일 전 (14일 이상 빨간색)

### 화면
- [ ] 전체 화면 버튼: 들어가기/나가기, Esc로 나간 뒤 버튼 상태 동기화
- [ ] iPad Safari: 전체 화면 버튼 표시 여부 확인 (미지원이면 숨김이 정상)
- [ ] 화면 켜두기 켜면 버튼 강조, 기기 화면 자동 꺼짐 시간이 지나도 화면 유지
- [ ] 화면 켜두기 켠 채 새로고침 → 첫 터치 후 다시 유지

### 오프라인·설치
- [ ] 한 번 접속 후 비행기 모드 → 새로고침 → 앱·위젯·저장 정상
- [ ] 홈 화면에 추가(iPad Safari 공유 → 홈 화면에 추가 / Chrome 설치) → 아이콘·이름 "ClassBoardKit", 주소창 없이 실행
- [ ] 새 버전 배포 후 열린 탭에 "새 버전" 알림 → 새로고침 → 데이터 유지

### 품질
- [x] Lighthouse Performance·Accessibility·Best Practices 각 90+ (배포 URL 기준 재측정) — 2026-11-05 데스크톱 99/100/100, 모바일 100/100/100

## 9. 위젯 확장 (M4)

> 자동 검증: `tools/e2e/m4.mjs` 72항목 (Edge). 아래는 실기기·사람 눈으로 확인할 항목

### 독
- [ ] 태블릿 세로(768px): 독 끝이 흐리게 보이고 밀어서 마지막(QR 코드)까지 추가 가능

### 주사위·카운트다운
- [ ] 주사위 1~6개, 굴리기 버튼·주사위 눌러 굴리기, 합계, 움직임 줄이기 설정 시 흔들림 없음
- [ ] 카운트다운: 날짜·시각 입력(iPad 날짜 선택기), D-day 표시, 지난 날짜 "지났어요"

### 그리기
- [ ] iPad + Apple Pencil·손가락으로 그리기, 그리는 중 화면이 스크롤·확대되지 않음
- [ ] 제목 막대로만 위젯 이동, 크기를 바꿔도 그림이 늘어나지 않음
- [ ] 지우개, 마지막 획 취소, 모두 지우기(확인 창)

### 이미지·배경
- [ ] 사진 앱/파일에서 이미지 선택(iPad), 큰 사진(4000px 이상)도 저장, 새로고침 후 유지
- [ ] 끌어 놓기·붙여넣기(노트북), 맞춤(전체 보이기/꽉 채우기), 대체 텍스트
- [ ] 보드 배경 "내 이미지" → 적용, 빈 보드 문구가 읽힘, 고대비 테마에서는 검정
- [ ] 사생활 보호(시크릿) 창: 이미지 기능만 안내 문구, 나머지 정상

### 백업
- [ ] 이미지가 있는 보드를 내보내기 → 다른 기기/브라우저에서 가져오기 → 이미지 그대로

### 소음 측정기
- [ ] "측정 시작" → 권한 창 → 막대가 소리에 반응, 경고 기준을 1초 넘게 넘으면 빨간 테두리·"조금 조용히!" (소리 없음)
- [ ] 권한 거부 → 안내 문구, 마이크 없는 기기 → 안내 문구
- [ ] 위젯 삭제·다른 탭 이동 시 브라우저의 마이크 사용 표시가 꺼짐
- [ ] iPad Safari·macOS Safari 동작 [검토]

### QR 코드
- [ ] 휴대폰 카메라로 스캔 → 입력한 주소가 열림 (라이트·다크·고대비 테마 각각) — 자동 판독 검증 없음 (ADR-0006)
- [ ] 오프라인에서 QR 위젯 처음 추가해도 생성됨

## 10. 공유·템플릿·실행 취소 (M5)

> 자동 검증: `tools/e2e/m5.mjs` 68항목 (Edge, 두 번째 프로필로 링크 열기·오프라인 포함). 아래는 실기기·사람 눈으로 확인할 항목

### 실행 취소
- [ ] 태블릿: 위젯을 실수로 지운 뒤 알림의 "실행 취소" 또는 툴바 ↶ 버튼으로 복원
- [ ] macOS: ⌘Z / ⌘⇧Z, Windows: Ctrl+Z / Ctrl+Y·Ctrl+Shift+Z
- [ ] 텍스트·명단 입력 중 Ctrl+Z는 글자만 되돌리고 위젯 위치는 그대로
- [ ] 한글 자판 상태에서도 단축키 동작

### 템플릿
- [ ] 6종 각각 만들어 보고 노트북(16:9)·iPad 가로·세로에서 겹침·잘림 없음
- [ ] 첫 방문(빈 보드)에서 "템플릿으로 시작하기" → 30초 안에 수업 보드 준비 (G1)

### 공유 링크
- [ ] 노트북에서 링크 복사 → 메신저(카카오톡·Slack·이메일)로 보내 다른 기기에서 열기 → 확인 → 같은 배치
- [ ] iPad "공유…" 버튼(Web Share) → 메시지·메일로 보내기
- [ ] 휴대폰 카메라로 공유 링크 QR 스캔 → 열림 (짧은 보드)
- [ ] 명단이 있는 보드: 기본(명단 제외)으로 보내면 받은 쪽 명단이 비어 있음
- [ ] Safari 16.4+·Firefox 113+에서 공유 메뉴가 보이고 링크가 열림 [검토]

## 11. 접근성·디자인 (M6)

> 자동 검증: `tools/e2e/m6.mjs` 58항목 (40개 화면 상태 axe 위반 0, 키보드·포커스·낭독기 알림·강제 색상·움직임 줄이기·200% 확대 포함), `tests/contrast.test.js`. 아래는 사람이 실제 보조 기술로 확인할 항목

### 화면 낭독기
- [ ] **NVDA + Chrome/Edge (Windows)**: Tab으로 건너뛰기 링크 → 보드 툴바 → 위젯 → 독 순서, 위젯 이름 "타이머, 위젯"과 조작 안내가 읽힘
- [ ] NVDA: 화살표로 위젯 이동 시 "가로 30%, 세로 23%" 읽힘, 랜덤 뽑기는 결과만 1번, 점수판 "1팀 5점", 타이머 종료 즉시 읽힘
- [ ] **VoiceOver + iPad Safari**: 독에서 위젯 추가, 위젯 설정 열기·닫기, 활동 상징 고르기
- [ ] VoiceOver (macOS Safari): 대화상자(템플릿·공유·단축키)를 닫으면 포커스가 보드 메뉴 버튼으로 돌아옴

### 키보드·화면
- [ ] 마우스 없이: 위젯 추가 → 이동·크기 → 설정 → 삭제 → Ctrl+Z, ? 키로 단축키 도움말
- [ ] **Windows 고대비 모드**(설정 → 접근성 → 대비 테마): 버튼·위젯 경계·포커스가 보이고, 신호등·팀 색·QR은 원래 색
- [ ] 브라우저 200% 확대: 툴바·독·메뉴·대화상자가 잘리지 않음
- [ ] OS "동작 줄이기": 뽑기·주사위 연출 없음, 타이머 종료 깜박임 없음

### 활동 상징·위젯 모양
- [ ] 활동 상징 12종을 교실 뒤에서 알아볼 수 있음 (프로젝터·대형 TV)
- [ ] 위젯 모양(기본·반투명·테두리) × 강조색 7종을 사진 배경·어두운 배경에서 확인 — 글자가 읽힘
