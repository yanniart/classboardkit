# ClassBoardKit v0.1.0 — 첫 공개 버전 (초안)

> 상태: **초안**. 태그·GitHub Release·Pages 배포는 원격 저장소 연결 후 진행한다.

설치·로그인 없이 브라우저에서 바로 쓰는 교실 위젯 보드의 첫 버전입니다.
모든 데이터는 사용 중인 브라우저에만 저장되며 어떤 서버로도 전송되지 않습니다.

## 주요 기능

- **위젯 8종**: 타이머(숫자/원형, 종료음), 스톱워치(랩), 시계(디지털/아날로그), 랜덤 뽑기(중복 제외), 모둠 편성, 점수판(2~8팀), 신호등, 텍스트
- **보드**: 여러 보드 관리(새로 만들기·이름 변경·복제·삭제), 배경 12종, 위젯 드래그·크기 조절 — 마우스·터치·키보드
- **백업**: 현재 보드 또는 전체를 파일로 내보내기·가져오기, 마지막 백업 시점 표시
- **수업 화면**: 전체 화면, 화면 켜두기, 테마 4종(시스템·라이트·다크·고대비)
- **오프라인**: 한 번 열면 인터넷 없이 동작, 홈 화면에 앱으로 설치
- **언어**: 한국어·영어 (브라우저 언어 자동 감지)

## 알아 두세요

- 브라우저 데이터를 지우면 보드도 지워집니다. **보드 메뉴 → 백업 → 전체 내보내기**로 가끔 파일을 저장해 두세요.
- iPad에서는 Safari "홈 화면에 추가"로 설치해 쓰는 것을 권장합니다 (데이터 보관이 더 안정적).
- 전체 화면·화면 켜두기 버튼은 지원하는 브라우저에서만 보입니다.

## 검증

- 단위 테스트 128개, 브라우저 자동 검증(Edge) 114항목 — 오프라인 새로고침·업데이트 흐름 포함
- Lighthouse: 데스크톱 100/100/100, 모바일 93/100/100 (Performance/Accessibility/Best Practices)
- 알려진 한계: Safari·iPad·Firefox 실기기 점검은 아직 진행하지 않음
