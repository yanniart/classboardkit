# ADR-0005: 오픈소스 라이선스

- 상태: **Accepted**
- 날짜: 2026-11-04

## 배경
개인 포트폴리오로 소스를 공개한다. 라이선스가 없으면 법적으로 타인이 사용·수정할 수 없다.

## 선택지
| 라이선스 | 특징 |
|---|---|
| MIT | 가장 관대, 포트폴리오에서 흔함, 저작권 표기만 요구 |
| Apache-2.0 | MIT 수준 + 특허 조항, 변경 사항 표기 |
| GPL-3.0 / AGPL-3.0 | 파생물도 공개 의무 → 복제 서비스의 비공개 상용화 방지 |

## 제안
MIT — 포트폴리오 목적에 부합하고 기여 장벽이 낮음.
