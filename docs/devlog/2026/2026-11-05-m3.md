## 문제와 해결
- 증상: E2E 오프라인 검사에서 "네트워크 차단" 확인이 실패
  - 원인: `Network.emulateNetworkConditions`는 페이지 요청만 막고 서비스 워커의 fetch는 막지 못함 → 오프라인이 아니었음
  - 조치: m3가 포트 8766에 자체 정적 서버를 띄우고 실제로 종료 → 진짜 오프라인 검증. 같은 서버로 업데이트 흐름까지 검증
- 증상: 보드 메뉴 "보드 내보내기"가 "보드 내보내/기"로 글자 단위 줄바꿈 (스크린샷)
  - 조치: 메뉴 폭 22rem, `.menu-button { word-break: keep-all }`
- E2E 하네스는 `console.warn`도 오류로 셈 → 예상된 실패(가져오기 거부, Wake Lock 거부, 전체 화면 거부)는 `console.info`로 기록
- `modulepreload` 43개 실험: 모바일 FCP 1.8→2.0s, LCP 변화 없음 → 되돌림 (목록 관리 부담만 생김)

## 결정 사항
- SW 캐시 버전은 수동 번호 대신 **앱 파일 해시** → 배포 때 버전 올리기를 잊을 수 없음 (테스트가 강제)
- 새 버전은 자동 적용하지 않고 사용자가 "새로고침"을 눌러야 적용 (수업 중 타이머가 끊기지 않게)
- 가져오기는 보드만 추가, 설정은 가져오지 않음. 실패 시 부분 가져오기 없음
- `storage.persist()`는 로드 시 호출하지 않음 (Firefox 권한 창)
- 데모 GIF는 생략, 스크린샷 4장으로 대체
