# ClassBoardKit v0.2.0 — 위젯 확장

**바로 사용하기: https://yanniart.github.io/classboardkit/** (2026-11-05 배포)

위젯이 8종에서 14종으로 늘었고, 보드 배경에 내 사진을 쓸 수 있게 됐습니다.
지금까지처럼 모든 데이터는 사용 중인 브라우저에만 저장되며 어떤 서버로도 전송되지 않습니다.

## 새 위젯 6종

- **주사위**: 1~6개, 주사위나 버튼을 눌러 굴리기, 합계 표시
- **카운트다운**: 행사 날짜·시각까지 남은 일·시간, D-day 표시 (지나면 "지났어요")
- **그리기**: 펜 6색·굵기 3단계, 지우개, 마지막 획 취소, 모두 지우기. 위젯 크기를 바꿔도 그림 비율 유지
- **이미지**: 파일 선택·끌어 놓기·붙여넣기(Ctrl+V), 전체 보이기/꽉 채우기, 대체 텍스트
- **소음 측정기**: 교실 소리 크기를 막대나 얼굴로 표시, 경고 기준을 1초 넘게 넘으면 빨간색으로 알림 (소리는 내지 않음)
- **QR 코드**: 주소나 글을 QR로 크게 표시, 인터넷 없이도 생성

## 그 밖의 변경

- **내 이미지 배경**: 보드 메뉴 → 배경 → 맨 끝 견본
- **백업에 이미지 포함**: 내보낸 파일에 보드가 쓰는 이미지도 함께 저장 → 다른 기기에서 가져와도 그대로 (가져오기 한도 30MB)
- 첫 화면이 더 빨리 뜸, 위젯이 많아진 독은 끝이 흐려져 밀어서 볼 수 있음을 표시

## 개인정보

- **소음 측정기**는 "측정 시작"을 눌렀을 때만 마이크를 켭니다. 소리는 기기 안에서 크기 숫자로만 바뀌고 **녹음·저장·전송하지 않습니다.** 위젯을 지우거나 다른 탭으로 가면 마이크를 끕니다.
- 이미지는 브라우저 안(IndexedDB)에만 저장되고, 어느 보드에서도 쓰지 않는 이미지는 자동으로 정리됩니다.

## 알아 두세요

- v0.1.0으로 만든 백업 파일은 그대로 가져올 수 있습니다. 반대로 v0.2.0 백업을 이전 버전에서 가져오면 이미지는 "찾을 수 없음"으로 보입니다.
- 사생활 보호(시크릿) 창 등 이미지를 저장할 수 없는 환경에서는 이미지 기능만 안내 문구가 나오고 나머지는 정상 동작합니다.

## 검증

- 단위 테스트 164개, 브라우저 자동 검증(Edge) 186항목 — 배포 URL에서도 전부 통과 (M4 72항목: 가짜 마이크, 이미지 포함 백업 왕복·변조 거부, 오프라인 QR·이미지 포함)
- Lighthouse (배포 URL): 데스크톱 100/100/100, 모바일 100/100/100 — 첫 로드 전송량(gzip) 116.9KB
- 위젯 20개(그리기 점 15,000개 포함) 보드에서 드래그 프레임 중앙값 16.7ms
- 알려진 한계: Safari·iPad·Firefox 실기기 점검, QR 휴대폰 스캔은 아직 사람이 확인하지 않음
