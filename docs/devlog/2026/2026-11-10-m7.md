## 결정 사항 (계획에 없던 선택 → 권장안)
- i18n-check의 "영어와 같은 값" 경고에서 **자리표시자를 빼면 글자가 없는 값**(`{names} → {groups}`)은 제외 — 번역할 것이 없음. 스페인어의 `widget`·`min`·`Digital`·`Total {n}`처럼 실제로 같은 말은 경고로만 남김(CI는 경고로 실패하지 않음)
- 복수형 범주 "필수"는 정수 0~1000에서 실제로 쓰이는 범주만 (es의 `many`는 1,000,000 같은 큰 수에만 쓰여 선택, 없으면 `other`)
- 일본어 글꼴은 `--font-sans` 뒤에 덧붙이지 않고 `:root:lang(ja)`에서 순서를 다시 정의 — 뒤에 붙이면 Windows에서 Malgun Gothic이 먼저 잡혀 한자가 한국어 자형으로 보임
- 번역 제안 링크 글자색은 강조색이 아닌 `--color-text` + 밑줄 (강조색은 3:1만 보장, 글자는 4.5:1 필요)
- `template.widgets`는 현재 화면에서 쓰지 않는 키지만 지우지 않음 (키 제거는 별도 정리 때)

## 문제와 해결
- ja·es 초안이 영어 정리(자리표시자 `{n}` 통일·모둠 문구 조각화)를 전제로 작성되어 있어 i18n-check 오류 12건 → en·ko·호출부(`board-menu`·`share-open`·`randomizer`·`groups`)를 맞춤. 도구가 바로 잡아 줌
- m7 첫 실행에서 두 번째 언어부터 위젯을 못 찾음: `localStorage.clear()` 뒤 새로고침하면 앱이 페이지를 떠날 때 보드를 다시 저장 → 빈 페이지로 나간 뒤 `Storage.clearDataForOrigin`
- 두 번째 실행은 모든 언어가 한국어로 돌았는데 검사는 통과(넘침만 보는 검사라) — 정보 줄의 제목이 전부 한국어여서 발견. 원인 ① 언어만 넣은 설정 객체는 검증에서 거부돼 기본값 ② **헤드리스 Edge는 새로고침 뒤 `navigator.languages`가 `["ko","en","en-US"]`로 바뀜**(`--lang`은 첫 로드만). → 설정 UI로 언어 변경, 언어별 첫 화면 검사를 넘침 검사 앞에 둠
- 768px에서 모둠 편성 "섞기" 버튼이 2~3px 넘침 (영어에도 있던 문제, ko는 짧아서 안 보였음) → 툴바 `flex-wrap` + 버튼 `flex: none`
- 일본어 가나가 듬성하고 버튼 끝 글자가 잘려 보임: `palt`로는 그대로 → 원인은 `system-ui`가 Segoe UI(가나 없음)로 잡혀 글자마다 대체 글꼴로 그려진 것. 일본어 순서에서 일본어 글꼴을 `system-ui` 앞으로 (`palt`는 유지)
