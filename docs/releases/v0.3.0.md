# ClassBoardKit v0.3.0 — 공유·템플릿·실행 취소

**바로 사용하기: https://yanniart.github.io/classboardkit/** (2026-11-09 배포)

실수는 되돌리고, 수업 보드는 템플릿으로 바로 만들고, 만든 보드는 링크 하나로 동료에게 보낼 수 있게 됐습니다.
지금까지처럼 서버·계정 없이 동작하며, 공유 링크도 서버를 거치지 않습니다.

## 실행 취소·다시 실행

- 위젯 추가·삭제·이동·크기 조절, 배경 변경, 보드 추가·삭제·이름 변경을 되돌릴 수 있습니다.
- 보드 이름 옆 **↶ ↷ 버튼**(태블릿), **Ctrl/⌘+Z**, 다시 실행은 **Ctrl+Y · Ctrl/⌘+Shift+Z**
- 위젯이나 보드를 지우면 뜨는 알림의 **"실행 취소"** 버튼으로 바로 복원
- 위젯을 옮긴 뒤 글을 쓰고 실행 취소해도 **쓴 글은 그대로**, 위치만 돌아갑니다. (위젯 안의 점수·명단·그림 변경은 실행 취소 대상이 아닙니다 — 그리기는 자체 "마지막 획 취소")
- 기록은 새로고침하면 사라집니다.

## 템플릿 6종

보드 메뉴 → **템플릿에서 새 보드**, 또는 빈 보드의 **"템플릿으로 시작하기"**

| 템플릿 | 위젯 |
|---|---|
| 수업 시작 | 시계 · 오늘의 목표 · 5분 타이머 · 신호등 |
| 모둠 활동 | 모둠 편성 · 15분 타이머 · 소음 측정기 · 신호등 |
| 발표 순서 | 랜덤 뽑기(중복 제외) · 스톱워치 · 점수판 |
| 퀴즈·게임 | 4팀 점수판 · 주사위 2개 · 30초 타이머 |
| 조용한 활동·시험 | 시계(초 표시) · 카운트다운 · "휴대폰은 가방에" · 소음 측정기(얼굴) |
| 쉬는 시간 | 10분 원형 타이머 · 안내 문구 · QR 코드 · 그리기 |

문구는 만들 때 선택한 언어(한국어·영어)로 채워지고, 만든 뒤에는 무엇이든 바꿀 수 있습니다.

## 공유 링크

- 보드 메뉴 → **공유 링크** → 링크 복사, 태블릿에서는 "공유…"(메시지·메일), 짧은 보드는 **QR 코드**도 표시
- 받은 사람이 링크를 열면 "공유된 보드를 추가할까요?"를 묻고, 확인하면 **새 보드로 추가**됩니다. 기존 보드는 바뀌지 않습니다.
- 그림이 아주 큰 보드처럼 링크가 너무 길어지면(32,000자 초과) 파일로 내보내도록 안내합니다.

## 개인정보

- 공유 링크는 보드 내용을 주소의 **`#` 뒤**에 압축해 담습니다. 이 부분은 브라우저가 서버로 보내지 않으므로 서버 기록에 남지 않습니다.
- 다만 **링크를 가진 사람은 누구나 보드 내용을 볼 수 있습니다.**
- 이미지는 공유 링크에 넣지 않습니다. 랜덤 뽑기·모둠 편성의 **학생 명단은 기본으로 빼고** 만듭니다 (필요하면 체크를 끄세요).

## 알아 두세요

- 공유 링크는 Chrome·Edge 103+, Safari 16.4+, Firefox 113+에서 만들고 열 수 있습니다. 지원하지 않는 브라우저에서는 메뉴가 보이지 않습니다.
- 저장 데이터 형식은 바뀌지 않았습니다. v0.2.0 백업 파일을 그대로 가져올 수 있습니다.
