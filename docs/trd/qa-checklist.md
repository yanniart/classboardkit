마일스톤 완료·릴리스 전에 기기별로 수행한다. 결과는 개발 로그에 기록한다.

## 1. 대상 환경 (NFR-001)

| ID | 기기 | 브라우저 | 입력 | 우선 |
|---|---|---|---|---|
| E1 | Windows 노트북 | Edge 최신 | 마우스·키보드 | 필수 |
| E2 | Windows 노트북 | Chrome 최신 | 마우스·키보드 | 필수 |
| E3 | MacBook | Safari 최신 | 트랙패드·키보드 | 필수 |
| E4 | iPad | Safari 최신 (가로·세로) | 터치 | 필수 |
| E5 | Android 태블릿 | Chrome 최신 | 터치 | 권장 |
| E6 | 노트북 | Firefox 최신 | 마우스 | 권장 |

## 2. 공통 (M0~)

- [ ] 첫 방문 시 브라우저 언어로 표시 (ko/en), 그 외 언어는 영어
- [ ] 설정 → 언어 전환 즉시 전체 문구(위젯 포함) 변경, 새로고침 후 유지
- [ ] 설정 → 테마 4종(시스템/라이트/다크/고대비) 전환 및 유지
- [ ] 시크릿 모드에서 "저장이 꺼져 있어요" 알림 표시, 앱은 정상 동작
- [ ] 콘솔 오류 없음

## 3. 캔버스·위젯 (M1)

- [ ] 독에서 위젯 추가 → 계단식 위치, 추가된 위젯에 포커스
- [ ] 제목 막대 드래그로 이동, 캔버스 밖으로 나가지 않음
- [ ] 오른쪽 아래 모서리로 크기 조절, 최소 크기 이하로 줄지 않음
- [ ] 위젯을 누르면 맨 앞으로
- [ ] 위젯 내부 버튼·입력 조작 시 드래그가 시작되지 않음 (터치 포함)
- [ ] 키보드: Tab으로 위젯 포커스 → 화살표 이동, Shift+화살표 큰 이동, Alt+화살표 크기, Delete 삭제
- [ ] × 버튼으로 삭제
- [ ] 창 크기 변경·태블릿 회전 시 배치 비율 유지
- [ ] 위젯 20개 상태에서 드래그가 끊기지 않음 (NFR-004)
- [ ] 툴바·독이 위젯에 가려지지 않음

## 4. 보드 (M1)

- [ ] 새 보드: "보드 n" 이름으로 생성·활성화, 빈 상태 문구 표시
- [ ] 이름 변경: 대화상자, Enter로 저장, 빈 이름은 저장 안 됨, 한글 IME 입력 중 Enter로 오작동 없음
- [ ] 복제: 원본 바로 뒤 "(사본)"으로 생성, 위젯 포함
- [ ] 삭제: 확인 대화상자(취소 시 유지), 마지막 보드 삭제 시 새 빈 보드 생성
- [ ] 보드 목록에서 전환, 현재 보드 표시
- [ ] 배경 12종 적용·유지, 어두운 배경에서 빈 상태 문구가 흰색
- [ ] 고대비 테마에서는 배경이 검정으로 고정
- [ ] 팝오버: 바깥 클릭·Esc로 닫힘

## 5. 위젯별 (M1 기본형)

### 타이머
- [ ] ±1분, ±10초 조정 (0:00 ~ 99:59)
- [ ] 시작 → 1초 단위 감소, 일시정지 → 계속, 초기화
- [ ] 0:00 도달 시 종료음(첫 상호작용 이후) + 깜빡임 + "시간 종료!"
- [ ] 진행 중 새로고침·탭 전환 후에도 남은 시간 정확
- [ ] 위젯을 낮게 줄이면 조정 버튼 숨김

### 텍스트
- [ ] 입력 내용 자동 저장·복원
- [ ] 글자 크게/작게(4단계), 정렬 순환
- [ ] 위젯 크기에 비례해 글자 크기 변화, 교실 뒤편에서 읽힘 (NFR-006)

## 6. 저장 (M0~)

- [ ] 조작 후 1초 이내 저장 (DevTools → Application → Local Storage `classboardkit:*`)
- [ ] 저장 데이터를 손상시키고 새로고침 → 알림 + `classboardkit:corrupt:*` 백업 생성 + 새 보드

## 7. 위젯별 (M2)

### 공통
- [ ] ⚙ 버튼은 설정이 있는 위젯에만 표시(스톱워치 제외), 완료·Esc로 닫힘
- [ ] 설정 패널이 위젯보다 길면 패널 안에서 스크롤

### 타이머
- [ ] 빠른 설정(1~30분) 선택 시 패널 닫힘·대기 상태
- [ ] 분·초 직접 입력 반영, 원형 모드에서 원이 줄어듦, 마지막 10초 빨간색
- [ ] 종료음 끄기 동작

### 스톱워치
- [ ] 1/100초 진행, 랩 기록(최신순), 정지 후 계속, 초기화

### 시계
- [ ] 디지털/아날로그, 12/24시간(오전·오후), 초·날짜 표시 토글, 언어별 날짜 형식

### 랜덤 뽑기
- [ ] 명단 붙여넣기(줄·쉼표), 중복 이름 제거
- [ ] 중복 제외 ON: 모두 뽑으면 버튼 비활성 + "모두 뽑았어요", 처음부터
- [ ] 연출 후 결과 표시, 움직임 줄이기 설정 시 즉시 표시

### 모둠 편성
- [ ] 모둠 수 / 모둠당 인원 전환, 모둠 크기 차 최대 1명, 다시 섞기
- [ ] 명단·규칙 변경 시 이전 결과 초기화

### 점수판
- [ ] ±1, 선두 팀 강조, 팀 2~8개, 이름·색 변경, 전체 초기화
- [ ] 이름 비우면 "n팀"(언어 전환 시 "Team n")

### 신호등
- [ ] 등 누르면 전환, 문구 편집, 빈 문구는 언어별 기본값
- [ ] 위젯을 가로로 넓히면 가로 배치
