## 문제와 해결
- 증상: M1 회귀에서 위젯 삭제 버튼 클릭이 설정 버튼을 누름
  - 원인: 설정 버튼에 `widget__remove` 클래스를 재사용 → 같은 선택자에 두 버튼이 걸림
  - 조치: 공통 클래스 `widget__action`으로 분리, 빨간 마우스오버는 삭제 버튼에만
- 증상: E2E에서 모둠 편성 설정의 아래쪽 입력 클릭이 독을 눌러 위젯이 추가됨
  - 원인: 설정 패널이 스크롤되는데 테스트가 화면 밖 좌표를 클릭 (앱 문제 아님)
  - 조치: 테스트 하네스가 클릭 전 `scrollIntoView`
- 증상: 모둠 카드 이름이 약 13px로 작음 (스크린샷) → `6.5cqh`(약 18px)로 확대
- M1 E2E 선택자 갱신: 타이머 버튼 클래스를 공통 `w-btn`으로 바꾼 데 따른 것
