# ClassBoardKit v0.5.0 — Español · 日本語

**바로 사용하기: https://yanniart.github.io/classboardkit/** (2026-11-10 배포)

스페인어와 일본어를 더해 이제 **English · Español · 日本語 · 한국어** 4개 언어로 쓸 수 있습니다. 브라우저 언어에 맞춰 자동으로 열리고, 설정에서 언제든 바꿀 수 있습니다.

> **Translations welcome / Se agradecen sugerencias / 翻訳の改善を歓迎します** — 스페인어·일본어는 첫 번역입니다. 어색한 말이 보이면 설정 → 언어 아래 **"번역 개선 제안"** 링크로 알려 주세요 (GitHub 이슈 양식, 어떤 언어로 써도 됩니다).

## 새 언어

- **Español**: 중남미·스페인 어디서나 자연스럽도록 지역 중립 표현 (`es-419`·`es-ES`·`es-MX` 등 모두 자동 선택)
- **日本語**: です・ます체, 학생이 보는 문구는 짧게. 일본어 글꼴(Yu Gothic UI·Hiragino)로 표시해 한자가 한국어·중국어 자형으로 보이지 않습니다
- 위젯 15종, 템플릿 6종, 메뉴·대화상자·화면 낭독기 알림까지 모두 번역

## 더 자연스러운 문구

- 영어에서 "1 day ago" / "2 days ago", "1 name" / "2 names"처럼 단·복수를 구분합니다 (예전 "day(s)" 표기 정리). 스페인어도 같은 방식
- 좁은 모둠 편성 위젯에서 섞기 버튼이 줄어들어 글자가 잘리지 않고 다음 줄로 내려갑니다

## 기여하는 분께

- 번역 검사 도구 `node tools/i18n-check.mjs`: 빠진 문구, `{name}` 같은 자리표시자 오타, 복수형 형태, 번역 안 된 것으로 보이는 값을 표로 보여 줍니다. 저장소 CI에서도 실행됩니다
- 복수형은 문구 값을 `{ one: '…', other: '…' }`로 쓰면 됩니다 (`Intl.PluralRules` — 라이브러리 없음)

## 알아 두세요

- 저장 형식·공유 링크는 바뀌지 않았습니다. 이전 버전 백업을 그대로 가져올 수 있습니다
- 언어 파일이 늘어 첫 로드가 약 13KB(gzip) 늘었습니다 (158KB, 예산 200KB)
