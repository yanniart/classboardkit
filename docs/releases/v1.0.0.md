# ClassBoardKit v1.0.0 — 안정화 / Stable

**바로 사용하기 / Open: https://yanniart.github.io/classboardkit/** (2026-11-11 배포)

v1.0은 새 기능보다 **약속**입니다. 지금 만든 보드·백업·공유 링크가 앞으로의 v1.x 업데이트에서도 그대로 동작하도록 형식을 고정했고, 누구나 위젯과 번역을 더할 수 있는 길을 열었습니다.

> v1.0 is a promise rather than a feature release: what you create now keeps working through every v1.x update, and anyone can now contribute widgets and translations. [English README](../../README.en.md) · [Contributing](../../CONTRIBUTING.md)

## v1 안정성 약속

다음 네 가지는 v1.x 동안 호환됩니다 ([ADR-0011](../trd/adr/ADR-0011-v1-public-contract.md)).

| 약속 | 의미 |
|---|---|
| **백업 파일** (`*.classboardkit.json`, `schemaVersion` 1) | v1.0 이후 내보낸 파일은 모든 v1.x에서 가져올 수 있습니다 |
| **공유 링크** (`#share=1.…`) | 보낸 링크가 계속 열립니다 |
| **저장 위치** (브라우저 저장소 키) | 업데이트해도 보드·이미지가 그대로입니다 |
| **위젯 계약** | 계약대로 만든 위젯은 v1.x에서 고치지 않아도 동작합니다 |

이것을 깨야 하는 변경은 v2.0으로 미루고, 없앨 기능은 최소 한 번의 minor 버전 동안 미리 알립니다. 지금까지(v0.1~v0.5)의 백업 파일·링크도 그대로 쓸 수 있습니다.
