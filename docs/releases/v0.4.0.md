# ClassBoardKit v0.4.0 — 접근성·디자인

**바로 사용하기: https://yanniart.github.io/classboardkit/** (배포 후 날짜 기입)

키보드와 화면 낭독기로도 모든 기능을 쓸 수 있게 다듬었고, 교실 활동을 크게 보여 주는 **활동 상징**과 보드 분위기를 바꾸는 **위젯 모양**을 더했습니다.

## 활동 상징 (새 위젯)

- 직접 그린 그림 12종: 조용히 · 손 들고 말하기 · 잘 들어요 · 혼자 해요 · 짝과 함께 · 모둠 활동 · 써 보세요 · 읽어요 · 발표 · 생각해요 · 정리해요 · 쉬는 시간
- 그림을 누르면 고르기 격자가 열리고(화살표 키로도 이동), 아래 문구는 원하는 말로 바꿀 수 있습니다
- 교실 뒤에서도 보이도록 그림과 문구가 위젯 크기에 맞춰 커집니다

## 위젯 모양

- 보드 메뉴 → **위젯 모양**: 기본 · 반투명 · 테두리 3가지와 강조색 7가지
- 보드마다 따로 저장되고, 내보내기·공유 링크에도 그대로 들어갑니다. 실행 취소도 됩니다
- 고대비 테마에서는 읽기 쉬운 기본 모양을 유지합니다

## 접근성

- **키보드만으로**: 첫 Tab에 "위젯 독으로 건너뛰기", `?` 키로 단축키 도움말, 대화상자를 닫으면 포커스가 원래 자리로
- **포커스 표시**가 사진·어두운 배경에서도 잘 보이고, 알림이 포커스된 위젯을 가리면 알림이 아래로 비켜납니다
- **화면 낭독기**: 위젯을 키보드로 옮기면 위치를 읽어 주고, 뽑기·주사위·점수·모둠 결과는 연출이 끝난 뒤 한 번만 읽어 줍니다
- **색 대비**: 팀 이름·신호등 문구·글자 색이 라이트·다크·고대비 모든 테마에서 기준(4.5:1)을 넘도록 조정
- **Windows 고대비 모드**와 **동작 줄이기** 설정을 존중합니다 (동작 줄이기에서 타이머 종료 깜박임이 오히려 빨라지던 문제 수정)
- 브라우저 200% 확대에서도 메뉴·대화상자가 잘리지 않습니다

## 그 밖의 변경

- 팀이 많은 작은 점수판에서 버튼이 겹치지 않음
- 사진 배경에서도 빈 보드 안내 문구가 읽힘, 시스템 다크 모드로 바뀌면 그리기 색이 바로 바뀜
- 보드 메뉴가 길어도 아래쪽 독에 가려지지 않음

## 알아 두세요

- 저장 형식은 그대로입니다(선택 항목만 추가). 이전 버전 백업을 그대로 가져올 수 있고, v0.4.0 보드를 이전 버전에서 열면 위젯 모양만 기본으로 보이고 활동 상징은 "지원되지 않는 위젯"으로 보존됩니다.
