## 문제와 해결
- 증상: 공유 대화상자에 "null" 글자가 보임 (스크린샷)
  - 원인: 조건부 요소를 `body.append(조건 ? 요소 : null)`로 넣음 → DOM `append(null)`은 문자열 "null"을 넣음 (`h()` 헬퍼는 거르지만 `append`는 아님)
  - 조치: 배열로 모은 뒤 `null`을 걸러서 `append`
- 증상: 모둠 활동 템플릿의 신호등(폭 14%)에서 "조용히 개별 활/동"처럼 단어 중간 줄바꿈
  - 조치: 신호등 폭 16%로 조정 + `.traffic__label`에 `word-break: keep-all`
- 증상: 실행 취소를 연달아 누르면 "실행 취소: …" 알림이 6초씩 남아 위젯 제목 막대를 가림
  - 조치: 확인 알림만 3초 (삭제 알림의 실행 취소 버튼은 6초 유지)
- 작업 중 Bash에서 `cat > file`을 heredoc 없이 실행해 입력 대기로 멈춤(CLAUDE.md 함정 그대로) → 중단하고 Edit 도구로 수정

## 결정 사항 (계획에 없던 선택 → 권장안)
- 실행 취소 범위에 **새 보드·복제·파일 가져오기**도 포함 (템플릿·공유와 같은 `addBoardsOp`로 공짜, 실수 복구에 유용)
- **언어 변경해도 실행 취소 기록 유지** (계획은 "사라짐"이었으나 지울 기술적 이유 없음 — 기록은 i18n 키라 바뀐 언어로 표시). 새로고침 시에만 사라짐
- 마지막 보드를 지워 자동으로 생긴 빈 보드는 실행 취소 때 **비어 있을 때만** 함께 정리 (위젯을 넣었으면 남김)
- 다시 실행할 때 쓰는 내용은 **실행 취소 순간의 스냅샷** (예: 위젯 추가 → 텍스트 입력 → 취소 → 다시 실행하면 입력도 돌아옴)
- 삭제 알림의 "실행 취소"는 그 삭제가 아직 가장 최근 기록일 때만 동작, 다른 작업을 하면 알림을 닫음
- 실행 취소 확인 알림 "실행 취소: 위젯 이동"(3초) 추가 — 태블릿에서 무엇이 되돌아갔는지 보이게
- 툴바 버튼 위치: 보드 이름 칩 오른쪽 (태블릿에서 한 손 조작, 오른쪽은 표시 설정 묶음)
- 단축키는 `event.code`(물리 키) 기준 → 한글 자판(ㅋ)에서도 동작, 열린 대화상자·위젯 설정 패널 안에서는 앱이 가로채지 않음
- 템플릿 배치는 위 10%(툴바)도 비움 (계획은 아래 12%만) — 테스트로 강제
- 템플릿 state는 `(t, base) => state` 형태로 **기본 state 위에 덮어쓰기** → 위젯 state 모양이 바뀌어도 키가 빠지지 않음 (테스트: 모든 템플릿 위젯의 state 키 = 기본 state 키)
- 빈 보드의 "템플릿으로 시작하기"도 **새 보드**를 만듦 (빈 보드를 바꾸지 않음 — 실행 취소로 쉽게 되돌릴 수 있게)
- 공유 대화상자: 명단 제외 체크박스는 명단이 있는 보드에서만 표시(값은 항상 기본 켬), QR 오류 정정은 L(최대 용량), 링크 입력란은 포커스 시 전체 선택
- 공유 링크 오류 문구는 가져오기 문구 대신 공유 전용 1개(손상·잘림·폭탄·형식 모두) + 새 버전만 기존 문구 재사용
- 공유 링크 32,000자 판정은 링크 **전체** 길이, 디코딩 쪽 상한은 조각 길이(같은 32,000자)
